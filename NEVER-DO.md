# Cue — never-do list (Phase 1)

Breaking any of these needs an explicit decision from Shannon, recorded in the plan doc.

- No accounts, servers or cloud storage before M5.
- No learning that changes priorities without Shannon's approval.
- Never automatically lower a protected category (health, safety, work attendance, hard deadlines, bills, sleep, dependents).
- Never invent certainty: an unknown is shown as unknown.
- No new devices (watch, car, desktop, voice) before Phase 3.
- The decision engine never calls an AI model directly; models sit behind the model adapter.
- Never two milestone branches open at once.
